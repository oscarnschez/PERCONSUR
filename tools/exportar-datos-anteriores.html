Exportar datos del sistema anterior

Esta página lee los datos que el generador de documentos anterior (NER 3.0) guardó en este navegador: borradores, fotos del borrador, consecutivos de folio y placas recordadas. Crea un archivo que después importas en la app nueva desde Ajustes → Importar respaldo.

Debe abrirse desde el mismo sitio (dominio) donde usabas el sistema anterior y en el mismo navegador; los datos locales no se comparten entre sitios. No modifica ni borra nada.
